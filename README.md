# NoiseCore Website

NoiseCore is a responsive e-commerce website designed for audio enthusiasts. The website showcases a variety of audio products including headphones, earbuds, speakers, and open-ear earbuds while providing users with product promotions and membership registration.

## Overview

NoiseCore is a fictional audio technology brand focused on delivering high-quality sound experiences through innovative products and modern design. The website was developed as a front-end web development project using HTML, CSS, and JavaScript.

## Features

### Home Page
- Hero section promoting membership registration
- Top 5 featured products
- Current promotions section
- Quick navigation to products and deals

### Products Page
- Product catalog display
- Category filtering:
  - Headphones
  - Earbuds
  - Speakers
  - Open-Ear Earbuds
- Interactive filtering using JavaScript

### About Page
- Company introduction
- Mission statement
- Core values
- Company journey and background

### Deals Page
- Special promotions
- Product bundle offers
- Membership promotion section

### Join Membership Page
- Membership registration form
- Client-side form validation
- User input verification:
  - Username validation
  - Email validation
  - Password validation
  - Gender selection
  - Date of birth validation
  - Terms and conditions agreement

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Responsive Design

The website is designed to be responsive and adapts to different screen sizes using CSS media queries.

Supported devices:
- Desktop
- Tablet
- Mobile

## JavaScript Functionalities

### Product Filtering
Users can filter products by category using the interactive filter menu.

### Form Validation
The membership registration form validates:
- Username length
- Gmail email format
- Alphanumeric password
- Gender selection
- Date of birth selection
- Agreement checkbox

## How to Run

### Method 1

Open the project folder and launch:

```text
HTML/Home.html
```

using any modern web browser.

### Method 2

Use Visual Studio Code with Live Server:

1. Open project folder in VS Code.
2. Install Live Server extension.
3. Right-click `Home.html`.
4. Select **Open with Live Server**.
